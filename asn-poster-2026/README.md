# ASN 2026 Poster Input

ASN Kidney Week 2026 の尿酸・蛋白尿・eGFR ポスター発表用の英語表現100題と、想定質問・回答50題を練習する Android アプリです。前の `eigakkaiwa_input` を参考に、内容と学習画面を別アプリとして作成しました。

## 使い方

- **音声で覚える**：1カードごとに①英語表現1回 → ②日本語訳1回 → ③発表用の短い例文2回。表示中のカードを現在位置から順に連続再生できます。再生中は停止できます。
- **フラッシュカード**：日本語を見て英語を思い出す、または英語を見て日本語を思い出す。タップして答えと例文を表示します。
- **想定Q&A 50題**：ポスターへの英語の質問と口頭で答えやすい英語の回答を収録。対象者、方法、結果は完成版ポスターの表現に合わせています。考察35題は10月11日の改訂前の会話調の回答に戻し、不要な重複や明らかな不整合のみ微修正しました。音声は質問1回（女性の声を優先）→ 回答2回（男性の声を優先）。Android版では端末にインストールされた複数の音声エンジンから英語の声を一覧表示します。「音声で覚える」画面で質問・回答の声をそれぞれ試聴して指定できます。声の性別を自動判別できない場合は警告を表示するので、実際の声を聴いて選んでください。選んだ声はアプリを閉じても保持します。候補がなければGalaxyの「設定 → ユーザー補助 → テキスト読み上げ」で英語音声を追加してからアプリを再起動してください。フラッシュカードでも同じ音声設定を使います。フラッシュカードでは質問を見て回答を思い出し、タップして回答を表示します。「ヒントを表示」を押すと、回答全文の重要な英語表現・語句を2〜4か所空欄にした英文が出ます。研究の数値は空欄にせず残します。次のカードではヒントが閉じます。日本語訳はありません。
- **考察の会話調を復元**：50題のうち35題が機序、因果関係、治療試験、臨床的意義、限界、今後の研究に関する質問です。カテゴリーの「考察のみ（35題）」からまとめて練習できます。[全50題](questions-and-answers.md)・[出典と確認事項](qa-sources.md)。設問の番号とテーマを維持し、Web版の既存の暗記状態も引き継ぎます。
- カテゴリー、検索、シャッフル、未暗記だけの表示、読み上げ速度の調整に対応します。「覚えた」は端末に保存されます。
- Android 版は両方の教材をAPKに同梱します。サーバーやアカウントは不要です。音声は端末の Text-to-Speech エンジンを利用します。英語表現とQ&Aの暗記状態は別々に保存されます。

## Android APK のビルド

Android Studio で `android/` を開き、JDK 17 と Android SDK 35 を設定して **Build > Build APK(s)** を実行してください。Debug APK は `android/app/build/outputs/apk/debug/app-debug.apk` に生成されます。Android 8.0（API 26）以上に対応します。

コマンドラインでは Gradle 8.9 を使用します。

```bash
python3 tools/generate_cards.py
cd android
gradle :app:assembleDebug
```

このリポジトリでは、ルートの `.github/workflows/asn-poster-apk.yml` が変更時にAndroid用のAPKをビルドし、Actions の `ASN2026PosterInput-debug-apk` 成果物として保存します。

以前のAPKはCI環境で生成された一時的なデバッグ鍵で署名されています。別のビルドから上書きインストールはできないため、更新する場合は以前のアプリをアンインストールしてから新しいAPKをインストールしてください。アンインストールすると端末内の暗記状態は消去されます。

## PWA での使用

`www/` は同じ150題を使うインストール可能な Web 版です。HTTPS のサイトとして設置すると Android Chrome の「ホーム画面に追加」から利用できます。初回表示後は静的ファイルを端末にキャッシュします。Web 版の音声にはブラウザの SpeechSynthesis を使います。

ローカルで動作を確かめる場合は `python3 -m http.server 4173 --directory www` を実行し、`http://127.0.0.1:4173/` を開いてください（ローカル HTTP ではオフラインキャッシュは有効になりません）。

## 設問の編集

`cards.tsv` が英語表現100題、`qa.tsv` が英語の想定質問と回答50題の元データです。`qa-hints.tsv` には覚えるべき英語表現・語句を設問番号ごとに2〜4個指定し、数値は空欄にしません。変更後は `python3 tools/generate_cards.py` で `www/cards-data.js` と `www/qa-data.js` を作り直します。対象者、方法、結果は2026年10月11日に完成版ポスターと「下書き_20261005.docx」を照合しました。10月12日には考察35題と英語表現のInterpretation・Limitationsの20題を改訂前の文章に戻し、通常の説明に重ねた不要な但し書きと明らかに不適切な説明のみ微修正しました。研究の限界を直接問う設問では元の説明を残しています。
